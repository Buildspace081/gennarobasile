## The model

**READ** systems interpret existing information. **WRITE** systems generate a new representation. **ACT** systems use tools or interfaces to change an external state.

The distinction is useful because a fluent answer and a reliable action require different controls. Reading asks whether the right context was understood. Writing asks whether the output is grounded and useful. Acting asks whether permissions, side effects and recovery are designed safely.

## Why it matters

“Agentic” is not a visual style or a synonym for a chatbot. It describes a system boundary: the model can select and invoke capabilities that affect something outside the conversation.

## Working questions

- What can the system observe?
- What is it allowed to change?
- Which actions require confirmation?
- How is an error detected and reversed?
